# 🥟 Lanchonete K.M - Sistema Web

Este é o projeto do site institucional da **Lanchonete K.M**, focado em apresentar o cardápio de salgados, a história da marca e canais de atendimento ao cliente.

## 📋 Sobre o Projeto
O site foi desenvolvido com foco em simplicidade e clareza, permitindo que os clientes consultem preços de itens como Coxinha de Frango e Kibe com Requeijão, além de facilitar o contato via WhatsApp e redes sociais.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização modularizada para facilitar a manutenção.
* **JavaScript:* O alerta de pedido via WhatsApp.

## 📂 Estrutura de Arquivos
O projeto está organizado da seguinte forma:
* `index.html`: Página principal com o status de abertura e tabela de preços.
* `salgados.html`: Seção de escolha de produtos e localização física.
* `contato.html`: Formulário de mensagem e links de redes sociais.
* `sobre-nos.html`: Seção institucional sobre a trajetória da lanchonete.
* `style.css`: Arquivo centralizador de estilos que importa as bases e o layout.
* `base.css`: Reset global de margens, paddings e tipografia básica.
* `layout.css`: Definições de cabeçalho, navegação, rodapé e container principal.

## 🎨 Design e Identidade
O projeto utiliza uma paleta de cores vibrante para o setor alimentício:
* **Fundo:** Cor de neve (`snow`) para conforto visual.
* **Destaques:** Dourado (`gold`) e Vermelho (`red`) para botões e detalhes importantes.
* **Botões:** Verde escuro (`darkgreen`) para ações de envio e contato.

## 🛠️ Como Executar
1. Certifique-se de que todos os arquivos estão na mesma pasta.
2. Garanta que as imagens estejam dentro de uma subpasta chamada `/imagens`.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
